# RYDA – Campus Transit, Unlocked

Official website for **RYDA**, a campus bike-rental service for students in Nigeria.

## Brand Identity
- **Name:** RYDA (written "Ryda" in the logo, "RYDA" in body copy)
- **Tagline:** "Campus Transit, Unlocked"
- **Website:** www.ryda.ng
- **Colors:**
  - University Navy: `#0A2D6B`
  - Electric Lime: `#7CFC00`
  - Pure White: `#FFFFFF`
  - Body Text: University Navy at ~80% opacity
- **Typography:**
  - Headings: Poppins (500, 600, 700)
  - Body & UI: Inter (400, 500, 600)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
